# Student Grade Tracker

A Java console-based application developed for the CodeAlpha Java Programming Internship.

## Features

- Add student names and marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Generate grade report
- Uses ArrayList for data management

## Technologies Used

- Java
- OOP (Object-Oriented Programming)
- ArrayList

## How to Run

Compile:

```bash
javac StudentGradeTracker.java
```

Run:

```bash
java StudentGradeTracker
```
